# Импорт и экспорт тренировок (JSON)

Кнопка «Импорт / экспорт» находится в окне «Мои тренировки». Код: `lib/workout-transfer.ts` (разбор, проверка, экспорт, пример и инструкция для ИИ), `components/workout-transfer.tsx` (интерфейс), `savedWorkouts.importDrafts` в `lib/saved-workouts.ts` (запись).

Публичные файлы для людей и агентов:

- `/workout-import-example.json` — рабочий пример;
- `/workout-import.schema.json` — JSON Schema (draft 2020-12).

Схема не выражает одно правило: `setOptions` должен содержать значение `sets`. Его проверяет приложение.

## Формат

```json
{ "version": 1, "workouts": [ { "label": "…", "title": "…", "restSeconds": 90, "soundEnabled": true,
  "exercises": [ { "name": "…", "sets": 3, "setOptions": [2, 3, 4], "reps": "10–12", "weight": "16 кг" } ] } ] }
```

Конверт: `version` (число, строго `1`) и `workouts` (массив из 1…50 тренировок). Других полей нет.

Тренировка, все поля обязательны:

| Поле | Тип | Правило |
| --- | --- | --- |
| `label` | строка | не пустая после обрезки пробелов; короткое название для кнопки |
| `title` | строка | не пустая; заголовок |
| `restSeconds` | число | секунды отдыха: ровно 60, 90, 120 или 180 |
| `soundEnabled` | boolean | `true`/`false` без кавычек |
| `exercises` | массив | 1…1000 упражнений; порядок массива = порядок выполнения |

Упражнение:

| Поле | Тип | Правило |
| --- | --- | --- |
| `name` | строка | обязательна, не пустая |
| `sets` | целое | обязательно, 1…100 |
| `setOptions` | массив целых | необязателен; непустой, уникальные значения 1…100, содержит `sets` |
| `reps` | строка | обязательна, не пустая; свободный формат («10», «12–15», «до отказа») |
| `weight` | строка | обязательна, может быть `""`; свободный формат («20 кг») |

Строки обрезаются по краям. Поля `id` и любые неизвестные поля отвергаются: внутренние ID не экспортируются, при импорте и тренировки (`user:<UUID>`), и упражнения (`ex-<UUID>`) получают новые локальные ID. Правила те же, что у репозитория (`validDraft`), поэтому всё, что принято разбором, принимается и записью; экспорт всегда можно импортировать обратно.

## Лимиты

- Текст: не больше 1 000 000 символов; файл: не больше 4 000 000 байт (проверяется до чтения).
- За один импорт — не больше 50 тренировок.
- В отчёте показывается не больше 20 ошибок (с пометкой, что список неполный).

## Поведение импорта

1. Вставка текста или выбор файла `.json`; файл читается и сразу проверяется.
2. «Проверить» разбирает весь пакет. Ошибки на русском с указанием места: «Тренировка 2, упражнение 3: поле «sets» — целое число от 1 до 100».
3. Кнопка «Импортировать» появляется только после успешной проверки текущего текста; любая правка текста сбрасывает предпросмотр.
4. Запись — одна операция: новые тренировки добавляются в конец каталога, существующие не изменяются. Любая ошибка (невалидный элемент, повреждённый каталог, квота, `write-failed`, недоступное хранилище) оставляет каталог как был, пользователь видит «Ничего не добавлено: причина». Ключ активной сессии (`ui-workout:state`) не читается и не пишется; идущая тренировка не меняется и не запускается.

Экспорт: JSON всех сохранённых тренировок в поле (выделяется по фокусу), кнопки «Скачать JSON» и «Копировать JSON». Если копирование недоступно, показывается сообщение с просьбой скопировать вручную. Блок «Составить тренировку с помощью ИИ» содержит полную инструкцию для агента и пример.
