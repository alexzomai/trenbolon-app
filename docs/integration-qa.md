## Честные ограничения

- Физических iPhone/Android в распоряжении нет. Блокировка/разблокировка реального экрана, Safari iOS, Chrome Android и слышимость сигнала на реальном устройстве не проверены.
- visibilitychange/focus/pageshow и media mocks не являются тестом системной блокировки экрана.
- Фоновое аудио best-effort. ОС может остановить декодер или вкладку; бесшумная часть WAV не гарантирует сохранение фонового воспроизведения. Для важных напоминаний на него полагаться нельзя.
- jsdom выводит Not implemented для HTMLMediaElement в части старых UI-тестов; специализированные media-интеграции используют управляемый mock, а не утверждают реальное звучание.
- npm ci сообщил 9 high severity vulnerabilities. Зависимости не обновлялись в этой интеграционной задаче.
- Изменения в scratch clone; для downstream использовать приложенный git bundle, не эфемерный каталог. Production deployment остаётся завершающей задаче t_1fe5de56.

## Передача

Bundle содержит полную историю интегрированной ветки. В репозитории назначения:

    git fetch /absolute/path/workout-integrated.bundle HEAD
    git merge --ff-only FETCH_HEAD

Fast-forward ожидается от cda4379 (текущее исходное состояние на момент начала интеграции). Если ветка назначения ушла вперёд, проверить divergence и переносить коммиты осознанно. Hotspot: components/workout-session.tsx (жизненный цикл редактора/аудио), lib/workout-state.ts (tick и snapshot).
